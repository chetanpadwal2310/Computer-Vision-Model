Computer Vision: Image Classification
This project uses TensorFlow/Keras and MobileNetV2 transfer learning to classify images into six categories: Buildings, Forest, Glacier, Mountain, Sea, and Street.
Features
Image preprocessing and augmentation
Transfer learning with MobileNetV2
Model evaluation and visualization
Interactive image predictions using Gradio
Technologies
Python, TensorFlow, Keras, NumPy, Matplotlib, Seaborn, Scikit-learn, and Gradio.
Getting Started
Clone or download this repository.
Install dependencies:
```bash
   pip install -r requirements.txt
   ```
Open and run `Computer_vision_Model.ipynb` in Google Colab or a compatible Jupyter environment.
Follow the notebook instructions to prepare the dataset, train/evaluate the model, and try image predictions.
Project Files
`Computer_vision_Model.ipynb` — Main notebook
`requirements.txt` — Python dependencies
Note
The notebook may use Google Colab-specific features. Dataset setup and file paths may need adjustment when running locally.
